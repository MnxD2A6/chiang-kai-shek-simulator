# 世界危机与曙光计划

依据用户确认的 Q1–Q9：保留实时地图，重大事件自动暂停；频繁荒诞事件及后续剧情；世界自主发生战争、阵营与合作变化；以 2–3 项事件选择为主，补充少量主动外交；科研采用简单投入档位；曝光可通过冻结、调查和让步挽回；核项目包含威慑、谈判结局与实际使用，使用后继续承担严重后果。用户已要求按推荐方案实施，保持简单操作。

## 一段完整体验

世界每 30 秒推进一周，筹备期和战争期都运转。重大新闻约 30–45 秒进入一次，自动暂停，玩家选一项后继续。较小消息进入新闻记录。世界事件有独立的随机序列，分支后续有明确的等待时间，未选和已选事件不会因重载被重复结算。

韩国剪刀石头布危机、希特勒复活传闻与欧洲反法西斯响应、俄罗斯失控机甲、巨型橡皮鸭封锁航道、外星误报等事件采用原创架空文本。不同选择带来后续故事、国家态度、制裁、援助转移，以及实际地图上的机甲 / 干预舰艇。国际新闻明确标记架空。

## 简单操作

新增“国际”按钮与新闻提示，侧栏只有“新闻 / 关系 / 机密”三个页签。新闻卡至多三项选择，直接写出成本与已知后果；无钱时始终有可选的零成本处理。可先看地图，重大决策未处理时保持暂停。少量主动行动为公开沟通、外交交涉和提出谈判，具有成本与冷却。

## 秘密项目

“曙光计划”仅用抽象进度、投入档位、暴露风险与国际关注呈现，不包含现实武器制造或侦察规避方法。启动花 100 资金。稳步与加速分别消耗约 1 / 3.2 资金每秒，进度约 0.30 / 0.65 每秒；暂停不推进并缓慢降低风险。经费耗尽自动暂停。完成得到一份战略储备；不要求核项目才能进行普通登陆战。

风险跨越阈值触发怀疑、调查、最后通牒。玩家可暂停 / 冻结、接受调查、公开谈判或继续承担压力。公开完成的项目可进入威慑并延后游戏中的空袭；谈判成功后可选择停火结局或继续自由战役。实际使用需要在游戏内二次确认，消耗储备、重创敌方战区，但引发制裁、撤援、国际舰队介入及后续危机，不自动赢得三城战役。

## 技术与兼容

零新增运行依赖。事件定义、规则、界面分别放入 world-events.js / world-core.js / world-ui.js，主 app 只接入生命周期与呈现。沿用现有舰艇、敌方地面部队、地理数据和绘制；增加世界局势标注。v7 自动存档使用独立键，迁移 v3–v6，不覆盖旧键。

## 验证

先写规则测试，覆盖时间冻结、分支排程、不可重复奖励、支援撤回与恢复、科研经费 / 档位、曝光阶梯、威慑、谈判胜利、核使用及干预实际出现、存档迁移 / 拒绝错误输入。实际浏览器从新局处理一个完整荒诞事件链、启动 / 调整项目并处理一次曝光；通过可见界面验证核项目及后果，不注入状态。测试与构建通过后更新 GitHub Pages，再核对公开页面与关键文件。
