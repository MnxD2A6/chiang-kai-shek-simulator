# 2.6 战前路线与事件后果

目标：同一张实时地图能采用不同准备方式；新闻选择留下任务、保障或限时合同，玩家能直接看见下一步。保留点单位、点目标的操作方式，没有新增硬性开战期限。

## 九条路线

经济、科技、外交达到1级后，可在「发展 → 战前路线」主动打开对应议题，也会自动遇到。每组只选一条，达到条件并筹备0.8周后，在验收新闻中兑现。三个组可以混搭；不要求全部升到3级。开战中止未兑现项目，已投入资金不返还；完成的收益保留。

| 组别 | 路线 / 签约费用 | 实际验收条件 | 兑现后的效果 |
| --- | --- | --- | --- |
| 产业 | 出口长单 / 100 | 经济2、日本合作且贸易有效 | 出口收入+3/模拟秒，受贸易环境影响 |
| 产业 | 本地韧性 / 100 | 经济2 | 城市建筑和工厂导弹损伤−20% |
| 产业 | 运输后勤 / 100 | 经济2、保有3艘运输舰 | 运输舰100→70资金；成功护航额外+80 |
| 防卫 | 联合防空 / 120 | 科技2、美国合作且军售条件有效 | 预警+4模拟秒；有真实防空时多拦1枚；秘密科研初始风险至少8 |
| 防卫 | 本地抢修 / 120 | 科技2 | 同样160资金的重建由12缩至8模拟秒 |
| 防卫 | 民防演练 / 120 | 科技2、民心至少65 | 疏散60→30；疏散人员损失系数0.35→0.20，疏散后的民心损失−25%；物理损伤不变 |
| 外交 | 延后俄援 / 90 | 俄罗斯态度至少0 | 常规俄援出发与抵达延后1周 |
| 外交 | 公开检修 / 80 | 国际观感至少65 | 俄援和机甲兵力−25%；紧张+10、俄方态度−15 |

## 新闻会留下什么

- **竹子货单**：35资金只支付备货，不能即时获得货款。后续可亲自指挥真实护航，或付70委托承运、等0.53周交付。成功到港后在新闻领取180资金，并得到三周受封锁、制裁、战争影响的民用续单收入。失败或未交付前开战损失35，不额外罚款；不允许重复结款。
- **港口加班**：实际累计港务投入达55后，可花35签四周绕行合同。鸭子封锁期间仍可维持既有日本贸易，关系、制裁仍需满足。到期明确询问是否花80再续三周，只询问一次，不自动扣钱。合同不会删除鸭子封锁状态。
- **光缆救援**：累计支援达到75后，可将合作转为两轮医疗保障。实际袭击的人员、民心损失各减20%，城市仍受损。用完后询问是否花90续两轮，只询问一次。
- **应急保险**：55资金投保两轮城市袭击应急支出的50%，不支付疏散、重建、拦截弹费用。两轮后可花70再续两轮，只询问一次。损伤与命中不受保险影响。
- **极光科研**：35资金支持三周公开交流，新科技工程12→8模拟秒；已开工工程保持原完成时间。到期可花40再续三周，只询问一次。科技满级后不再出售无用途的工程加速。
- **美国预算**：本轮公开采购累计投入至少80，可建立两次防空快速交付资格，24→18模拟秒；每套仍需900资金、满足军售许可。满额部署后不能再付费购买无用途资格。
- **其他故事**：歌唱外交仍影响实际未抵达的朝鲜援军；机甲召回仍削弱真实存在的机甲。新故事的免费收尾不再返还从未投入的资金。

新增七个兑现、失败、到期、战后回访事件，复用对应故事的现有手绘插图。所有事件保留免费退出或接受现状选项。保障可叠加，但不会令导弹停止伤害建筑。

## 操作与兼容

「发展」显示路线验收条件、已选路线和「事件留下的影响」；「国际 → 新闻」同样列出合同、剩余保障与下一步。货运事件选亲自护航后，自动选中驱逐舰并定位行动区域，仍由玩家点击目标指挥。

新增v12存档键，保留原v11及更早实时存档。导入旧档不追溯发放未签署的医疗、保险或订单，旧军队、城市、路线收益照常保留。已完成议程保持原路线；想比较新路线可开始新战役。

军事胜利仍要求三城守满一周、抵御两轮空袭、击退两次实际登陆且台湾安全；本次没有改动这些条件。
