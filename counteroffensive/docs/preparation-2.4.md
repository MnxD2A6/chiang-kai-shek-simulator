# 2.4 战前议程

保持实时地图、简单点选和当前手绘美术。新的发展循环是：投资 → 遇到议题并选路线 → 达成条件 → 在后续新闻中兑现。国际观感、贸易和合作会影响条件与结果。

## 如何开始

1. 点“发展”，投资经济、科技或外交到1级。经济项目预留100、科技项目预留120、外交项目预留90资金。
2. 符合条件的项目随机出现；两个方案任选一个，也可免费“稍后再议”。暂缓项目在议程中可“重新洽谈”。
3. 发展面板显示还差的条件。签署后至少筹备0.8周，且达成实际条件，才会发出验收新闻；点击对应选项才生效。
4. 开战会中止所有未兑现的已签署或待办理项目，投入不返还。已完成收益保留。筹备没有周数截止线。

## 三个议题与六种路线

| 议题 / 签署预算 | 路线 | 验收条件 | 实际作用 |
| --- | --- | --- | --- |
| 日本产线订单 / 100 | 出口 | 经济2级、日本合作、日本贸易可用 | 基础收入每模拟秒+3，再按当前贸易、舆论等收入倍率计算；日本贸易受阻则暂停 |
| 同上 | 城市加固 | 经济2级 | 导弹对城市建筑与工厂的物理损伤减少20%；不保护人员，不免民心和应急支出 |
| 防空与抢修合作 / 120 | 联合校准 | 科技2级、美国合作、军售许可 | 预警增加4模拟秒；有实际防空系统时每轮多拦1枚，最多5枚，仍消耗拦截弹；秘密科研初始风险至少8% |
| 同上 | 本地抢修 | 科技2级 | 城市重建由12缩短至8模拟秒；仍需160资金，恢复量不变 |
| 俄方机甲售后风波 / 90 | 协调排期 | 俄罗斯态度≥0 | 常规军援出发与抵达延后1周；已有舰队不撤回 |
| 同议题 / 80 | 公开检修 | 国际观感≥65 | 俄方常规援军与机甲陆军兵力减少25%；地区紧张+10、俄罗斯态度−15；舰船耐久不变 |

验收时也可以取消，回收40资金，项目结束。另一条未签署路线不可领取。普通国际事件仍会随机打断或提供机会，例如半岛危机影响军售、贸易事件影响出口、公开回应提高观感。

默认每真实秒推进0.5模拟秒，2倍速为1模拟秒。页面会把收入、等待时间和预警时间换算为当前速度下的显示值。默认出口基础加成为每真实秒1.5，联合预警延长8秒，本地抢修24秒缩短至16秒。

日本贸易需要日本合作、日本态度高于−30、制裁低于2级且无鸭子封锁。联合战斗收益需要美国合作、美国态度至少+10、无制裁且半岛航路可用；条件失效时收益暂停，项目完成记录保留。联合监管对科研初始风险的代价保留。

新版本共有40个事件、103项回应，原34个事件与海报保留，6个筹备事件复用相关海报。没有改成像素风。存档为v11，仍能导入旧实时存档；六角格入口保持独立。

所有数值、外交条件与剧情均为架空游戏规则。
