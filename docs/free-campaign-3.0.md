# v3 自由战役：设计与实施

目标：玩家自己决定调兵、攻城和守城的城市顺序。保留点击部队/目标、暂停下令的简单操作，继续公开 GitHub Pages 与零运行依赖。所有地图、阵营、部队与事件为架空玩法。

## 玩法与结构

- 大地图有十二座互相连通的城市、三支独立军团、敌军军团、城市守备与城防。开局控制西部三城，目标城市自由选择。
- 点军团，再点城市即安排路线：己方城调兵、同城驻守、中立城接管、敌方城攻城。路径只经过己方或中立地区，不能越过未攻下的敌城。
- 每次「推进一天」沿道路走一段。城市提供补给，驻守军团自动修整；出征耗费少量补给。敌军按邻近阵地与薄弱防线调动和反攻。
- 遇到战斗可亲自打、快速结算或撤回。实时战场由城市地形、守备、城防和参加军团生成，兵力与战损回写大地图。守城战可由驻军或当地守备抵抗；撤回攻城不会丢掉己方城市。
- 三军团可协同攻同一城，抵达时间相同则合成一次战斗。军团移动、路线、守备、归属变化都有可见标记。攻下全部城市后可继续自由调动，失去全部城市则有明确重开入口。
- 只突出当前选择、兵力与补给。造兵/修城仅两个明确费用的按钮，自动收入，不要求财政公式或行动点。
- v3 存档独立。导出包含当前战役、部队路线及待处理战斗；刷新后可重新集结未结算战斗，已经结算的战损/占城只记一次。

## 实施与验证

1. campaign-core.js 与行为测试：道路、独立路线、推进、协同进攻、中立接管、驻守、资源、敌军反攻、胜败与存档。
2. tactics.js 增加自由攻城/守城战场生成，复用寻路、选兵、暂停、射程和救护；frontline-view.js 绘制城防并显示真实地形。
3. campaign.js / campaign.css 提供大地图、军团列表、命令预览、战场、简短引导和独立存档。app.js 提供三个玩法入口。
4. 浏览器实际调兵、攻城、守城、撤退、快速结算、存档恢复和窄屏操作；保留 v2 测试。
5. 更新版本、说明与范围明确的发行包，验证后推送 GitHub Pages，确认匿名网页与新资源可访问。

验收不能仅靠新增城市按钮或数字动画：真实军团有所在城市、逐日路线和战损，敌军可攻下城市；任意合规前沿城市都可自由攻守，而非三场固定任务的顺序包装。
