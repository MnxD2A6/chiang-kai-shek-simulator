# 蒋介石模拟器：另一条时间线

2026-10-12。用户要求可玩的 2D 蒋介石模拟器、可发布 GitHub，并选择同时包含历史策略、像素角色扮演、搞笑沙盒。

## 游戏

单人、中文、纯静态网页。12 个关键节点覆盖 1936–1949；史实仅作为背景，选择、数值、角色对白与所有结局均为架空。每回合三个行动点，必须先处理事件才能推进；事件决策不消耗行动点。管理国库、粮秣、军备、民心、外交和通胀；9 个城市有独立守备和民生。预测本轮受袭城市和战力，给玩家明确决策依据。坚持到终章后按城市数量、民心、通胀、外交区分结局；民心归零、只剩一个城市或持续断粮会提前结束。

v1.1 根据用户“basic、不知道怎么玩”的反馈升级：参见 `upgrade-1.1.md`。实际操作驱动的第一轮教学、大型作战室、点击寻路、持久方针、顾问信任、每轮任务、可见战报和工业容量限制均已加入。新局和解结局要求至少七项任务，旧存档不追溯过去任务。

像素作战室：WASD/方向键移动，E 互动；地图桌打开战略地图，三位顾问打开对应命令；鼠标点击人物也可互动。碰撞、行走动画、对话和指令与策略层使用相同状态。触屏提供方向键和互动键。完成 12 轮的一局预计 10–15 分钟。

戏剧模式：在历史背景事件中提供明确标记的架空选项，讽刺对象为官僚失灵、行政混乱和个人处境。玩家可随时切换模式。不对战争受害者作笑料。

## 结构

无运行时依赖、无账号或 API。经典 script 标签支持双击 index.html；GameCore 的纯状态机同时提供浏览器全局和 CommonJS 导出。content.js 管理事件和城市数据；engine.js 管理状态、行动、事件、结算、存档验证；room.js 管理像素场景；app.js 管理 DOM、声音和本地保存。地图为抽象 SVG 战区示意图，像素素材和 WebAudio 音效为原创程序绘制。提供静音选项，默认关闭音效。

存档 localStorage 一个槽位；导入/导出 JSON；schema 版本 1，对异常字段、城市集合、事件索引和数值范围严格验证；失败保持当前局。新游戏必须二次确认，确认界面展示具体后果。状态变更自动保存，存储不可用提示但仍可玩。

用户追加电话玩法：每轮总机来电连接同一事件；主动拨号可联络军事、外交、财政、运输和戏剧模式的总机闲聊。查看和挂断免费；执行请求消耗一个行动与显示的资源。通话文案全为架空，不调用现实通信服务。

## 交付和验证

独立项目目录，不触碰已有项目。提供 MIT 许可、README、史料链接、Node 22+ 测试和构建脚本、GitHub Pages Actions 工作流；仅生成本地发布包，本请求不视为已授权公开上传。

先测试关键状态不变量：越界/透支拒绝、事件只处理一次、确定性结算、存档往返/异常拒绝、多结局可达。再验证浏览器实际交互：开始游戏、角色移动、顾问互动、地图选城/执行、事件选择、结束回合、保存恢复、手机布局和最终局。记录测试证据，用户游戏体验验收保留。
