# v1.1 可理解性与游戏体验改进

用户反馈：初版 basic，而且不知道怎么玩。检查确认：启动页只有气氛文案；场景被缩成左侧小图；当前目标藏在帮助里；命令只显示成本，效果依赖 hover；结束回合只留下日志；电话对白与后续状态无关；工业可在同城反复堆叠。

## 改进

默认先进入大型作战室，地图为可切换主视图；点击地板自动寻路，点击人物走近再互动，保留 WASD/E。第一回合教学依玩家实际操作推进：接听、决策、地图、重庆、两次工业、结算。所有步骤可跳过，之后可重开教学。

一直显示最终目标与本轮具体任务。每轮任务明确进度和奖励，结算一次；结算报告呈现战斗、资源差值、任务成功/失败以及下一轮风险。命令同时显示效果和成本。

添加持久施政方针：均衡、守势（战力 +8/财政支出 +8）、动员（每轮军备 +5/粮秣 −4/民心 −4）、民生（每轮民心 +4/粮秣 +3/财政支出 +10）。更换花费 8 国库与一个行动，每回合最多一次。

顾问信任初值 50，每次电话请求 +7；同一联系人每轮最多一次请求，75 信任起有对应额外资源。低军备、通胀和断粮会使相关信任下降。城市最多三次工业建设，总工业上限 20；旧存档保留已有状态，补齐新增字段。

不产生付费生成费用。保留 v1.0 ZIP；新版另打 v1.1 ZIP。沿用纯静态文件、MIT、GitHub Pages 结构。技术验证和实际浏览器教学试玩分别记录，玩法验收不以测试代替。
