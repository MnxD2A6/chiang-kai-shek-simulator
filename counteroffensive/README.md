# 渡海 · 六角格回合战略 2.0

[直接玩](https://mnxd2a6.github.io/chiang-kai-shek-simulator/counteroffensive/?v=2.0.0)

选部队→点格子/城市→结束回合。真实海岸线和城市坐标保留，底层移动为六格邻接；国际事件、手绘素材、照片和音效继续使用。10–20分钟是设计目标；手动完整试玩17回合获胜，规则指令模拟19–24回合获胜，不把这些回合数当成人类用时结论。

## 核心规则

- 陆军每回合2行动点，舰船3行动点。移动一格、补兵一次或进攻消耗行动点；每军每回合最多进攻一次。新建部队下回合恢复行动点。
- 高亮仅表示当前实际可达范围。远处目标保留路线，结束回合时使用剩余行动点继续行进。缺运输时显示等待，空舰会用自己的行动点前往接运；每舰搭载一军，载兵舰通过陆军改令。
- 补兵最多转入500预备兵；每次消耗1行动点。组建军队消耗250预备兵，最多六军。经济提高收入、兵力容量和增长；科技降低损耗；外交延长后续空袭间隔。项目每次一项，需要一回合。
- 攻击前显示实际可造成的损失和预计自损，守军不足时不会显示虚假的超额伤害。占城需要陆军；导弹与舰炮不能直接占领。
- 运输舰100资金，驱逐舰180，导弹艇130；舰船维修40资金恢复100舰体。导弹每发40资金、消耗一枚，射程14格，每三回合补一枚至最多五枚。
- 开战后首次空袭3回合抵达，朝鲜援军4回合、俄罗斯援军7回合。局势可能取消援军。疏散35资金，下一轮空袭减伤70%；修复60资金恢复25点设施，每回合一次。
- 军事胜利需同时控制福州、广州、南京并守住两轮。科研完成后保留未使用储备，公开威慑再签署停火，可达成另一结局。设施归零、本岛全部失守或30回合窗口耗尽会显示明确败因。

## 国际与机密

每回合最多打开一条重大事件，后续排队保留；回应不会推进回合。有新闻待决时，结束回合按钮会带你回应。34个事件与85项选择保留，延迟改为回合；事件中的贸易封锁、舆论、制裁、机甲和干预都影响实际状态。

秘密科研只包含抽象经费、进度、风险与投入档位。稳步每回合25资金/进度+8/风险+4；加速50/+14/+9；暂停不花钱、风险−4。公开威慑延后下一次空袭两回合，后续谈判可以停火。实际使用会关闭此结局并触发制裁与干预，不会直接获胜。

## 操作和存档

拖动平移，滚轮或按钮缩放。数字1–6选择陆军；空格打开结束回合确认。手机从底部“部队/管理”打开面板，结束回合按钮始终位于底栏。

自动存档键为 `strait-front-hex-v1`；导入时检查坐标、行动点、载兵链接、固定城市与结局。旧实时存档不会强行转换，[1.11实时版](realtime.html)继续使用原v7存档。[1.11旧说明](docs/README-realtime-1.11.md)保留，历史版本中以秒计时的规则不适用于2.0。
