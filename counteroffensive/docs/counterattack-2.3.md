# 2.3 后续反击与军事胜利

军事胜利需要同时满足：控制福州、广州、南京；保住台北、高雄；三城与台湾连续在手一周；实际经历至少两轮城市导弹袭击；击退至少两次实际出港的登陆行动。仍在预警的城市导弹、集结或渡海的登陆舰队、未消灭的台湾登陆部队都会阻止结算。

三城守城进度到100%后会保留，等待反击条件完成；丢失任意目标城或台湾城市会清零。已经完成的空袭与反登陆次数保留。计数不要求额外点击，战斗与防空自动运行，点选、驻守、补兵、疏散、重建的操作不变。威慑停火仍是一条独立结局路线。

登陆公告不等于击退。运输舰全部被击沉且没有剩余登陆部队，或实际上岸部队被守军消灭后，才记一次。战斗未结束时不覆盖成下一轮；击退后休整两周，再组织下一次行动。主要港口失守时可从仍在大陆控制的沿岸出港。舰队未能出港、路线失败和船只数量达到上限均不记防守胜利。
