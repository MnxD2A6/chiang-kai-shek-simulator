# 事件海报素材

34 张原创事件插图，用于世界快报。每张对应 `world-events.js` 的同名事件，包含所有后续与结局节点。

以用户提供的历史海报为画风参考：朱红、墨黑、旧纸、橄榄灰；粗笔触、强烈斜线构图与石版印刷颗粒。画面为架空剧情创作，没有复制参考原图。地图与原有赛璐璐作战界面保留。

使用 OpenAI 内置 `image_gen` 的 generate 模式，一张事件一个独立提示词。没有调用收费外部生成接口。原始 PNG 保存在 `assets/event-posters/`，单张1536×1024，网页只加载当前新闻的插图。

完整提示词、对应文件、字节数及 SHA256 见 [素材清单](../assets/event-posters/manifest.json)。页面排版通过 CSS 适配横屏与窄屏；未对原始图片做二次像素编辑。
