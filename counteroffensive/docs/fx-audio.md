# 1.8 特效与音效

日期：2026-10-14。

## 画面

- 炮口闪光、短促后坐力、双色曳光与命中火花共享真实射击事件。
- 导弹飞行附带逐渐散开的赛璐璐尾烟。
- 新增 `water-impact-atlas.png`，六帧从接触、水柱到泡沫消散，由内置 image_gen.imagegen 生成；原图、提示词、透明通道与哈希记录在 `assets/battle-cel/manifest.json`。
- 海面命中叠加水花、椭圆波纹、碎片与余烟，陆地命中使用冲击圈与火花。特效上限 36 组，击沉和大型爆炸余烟约 2.7 秒。
- 航迹按真实移动方向绘制；暂停冻结特效，减少动态效果设置会关闭粒子、拖尾和后坐力。

## 声音

17 张原创单声道 44.1 kHz / 16 bit PCM WAV，合计约 1.75 MB。声源为固定种子噪声、滤波、振荡器、瞬态与包络分层，没有使用第三方录音或收费生成接口。WAV 按 MIT 许可随项目提供，元数据在 `assets/audio/manifest.json`。

`python scripts/generate-audio.py` 可重现素材，需要 numpy 与 scipy；发布和游玩不需要 Python。网页只读取已保存的 WAV。

`battle-feedback.js` 只观察真实战役事件，区分首次载入、暂停、发射、炮战、命中、警报与城市变化；每个事件触发一次声音。暂停下达的新导弹命令会在恢复时发声，载入旧存档不会重播旧战斗声音。

`battle-audio.js` 使用 Web Audio API：首次用户交互解锁，最多 10 个同时声源，按类型节流，立体声位置与地图对应，动态压缩限制叠加音量。脚步 / 引擎仅跟随选中移动单位，环境声默认关闭。静音、零音量和页面隐藏停止当前声音；暂停停止战场、移动与环境声，保留主动试听和界面反馈。

音量设置保存在独立的 `strait-front-audio-v1`，战役继续使用 v5。声音面板有音量滑块、静音开关、环境声选项、试听按钮和实际输出电平指示。
