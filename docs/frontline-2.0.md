# v2.0 前线冒险设计与执行计划

用户目标：走动场景、人物互动和电话内容更丰富，减少阅读与经营门槛，实际控制军队。继续零依赖网页与公开 GitHub Pages 发布；保留旧经营模式和旧存档。所有场景、部队与对白为架空游戏创作。

## 设计

- 默认前线冒险，经典经营通过独立入口进入。前线只显示当前目标、补给和士气；无行动点或强制经营。
- 五个场景：作战室、营地、补给站、村庄、前线指挥所。WASD / 方向键走动、点击寻路、E / 点击人物交谈，出口可穿越；手机同样可操作。
- 人物各有问答分支和实际帮助。救援支线需要取得药箱并交给村庄医生；奖励医疗支援，完成记录防止重复奖励。
- 三场战斗：桥头夺控、护送运输车、村庄防守。玩家指挥步兵、机枪、炮兵及医疗队。地形约束路径，敌军自动推进，交战受射程和掩体影响。命令是实际移动、攻击、停守与撤退。暂停时可以下令。
- 初次战斗以选中部队 → 点击桥头 → 点击敌军的互动提示引导。胜败由阵地、运输和部队生存决定。失败可重试；不永久扣除战斗前资源。
- 七条电话线路，每条有多种话题和阶段对白。可请求实际援军、弹药或救护；每阶段支援有明确限制，查看对白免费。
- 独立、严格校验的 v2 冒险存档，不触碰 v1 经典存档。战斗中的刷新保留已完成任务，当前战斗重新集结；界面明确说明。可导入、导出。

## 实施顺序

1. 为战斗命令、寻路、射程、胜败、支援、场景和存档写行为测试，观察失败。
2. 实现可独立测试的战斗和冒险核心，运行测试。
3. 实现场景绘制、走动、对话、电话、战斗视图及短教学，接入默认入口与经典模式切换。护送任务提供实际跟随粮车的命令。
4. 浏览器实玩全部三场战斗、支线、暂停、电话支援、存档恢复与手机宽度；修复实际问题。
5. 更新 README、版本和打包清单。保留 v1.1.1 包，生成 v2 包。测试与构建后推送，确认 GitHub Actions 成功、公开 URL 免登录可玩。

## 验收

不能用仅数字加减代替指挥军队。至少验证两个部队的独立移动与进攻、无法穿越河岸、敌军反击、真实阵地/护送胜败、暂停下令、重试无死锁，以及五场景可达、人物与支线奖励不重复。技术测试、浏览器实际试玩和用户对玩法的评价分开报告。
