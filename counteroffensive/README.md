## 特效与声音

1.8 加入炮击后坐力、双色曳光、导弹尾烟、海面水花、冲击圈与爆炸余烟。17 个原创音效对应指令、枪炮、导弹、命中、击沉、警报与占城；仅选中且正在移动的单位播放脚步或引擎声。

右上 **♪** 打开声音设置：启用 / 静音、0–100 音量、可选海面环境声，以及「试听炮击 / 水花 / 爆炸」。首次点击后载入声音；暂停或切换网页会停止战场声音，暂停时仍可试听或听到短促指令反馈。音量与静音设置单独保存，不改变战役存档。

音效为本项目离线合成的原始 WAV，没有外部服务或收费接口。素材与实现记录见 [1.8 声光说明](docs/fx-audio.md)，实测范围见 [1.8 QA](docs/QA-1.8.md)。

## 手绘地图、单位与战斗动画

1.7 将地图上的方块单位换成透明赛璐璐素材：四帧步兵行军、运输舰 / 驱逐舰 / 导弹艇、山林与城市。地图使用浅绿陆地与蓝色海面，保留 Natural Earth 的真实海岸线和城市坐标。单位没有方块底座，橙色圆标表示我方，黄色表示敌方；选中单位有地面环与名称。

行军使用逐帧动画，航行显示尾流；自动炮击显示炮口闪光和曳光，导弹与爆炸使用手绘图集。视觉反馈跟随真实战役时间，暂停时冻结，系统减少动态效果设置会降低运动。放大后显示大单位，缩到世界地图时隐藏近战特效。素材与生成提示词见 [地图美术说明](docs/battle-cel.md)，实测记录见 [1.7 QA](docs/QA-1.7.md)。

## 战术指挥界面与海战

1.6 使用纸白、墨黑、橙色的 2D 赛璐璐手绘 UI：移动 / 进攻命令配黑橙速度带，空袭预警用黄黑警示条包围，飞行导弹附带警告徽标。照片采用倾斜相纸构图，选中信息与四个命令保持清晰。四张透明 PNG 与完整生成提示词见 [赛璐璐素材说明](docs/cel-ui.md)，实际浏览器检查见 [1.6 QA](docs/QA-1.6.md)。

首页和人物面板保留蒋介石的 1945 年历史照片，来源与许可见 [照片说明](docs/portrait-photo.md)。军队与舰船统一图标避让，完整名称放在列表与选中面板；移位图标有细线指向真实位置。空间不足时从列表选单位。美术资源随静态包运行，不需要生成服务或 API key。旧版设计与立绘记录见 [1.5 UI 说明](docs/tactical-ui.md)。

- 初始舰队：两艘运输舰、一艘驱逐舰、一艘导弹艇。右上「部队列表」切换「陆军 / 舰队」，也可直接点地图图标，再点目的地下令。
- 运输舰自动承接附近陆军的渡海路线；缺少附近运输舰时军队等待。载兵运输舰被击沉，损失 70% 兵力并停止航行。
- 驱逐舰、导弹艇自动攻击射程内的敌舰。驱逐舰拦截附近敌方导弹。选舰后点敌舰驶近交战，点城市驶向近海。
- 「导弹打击」再点敌舰或敌方城市：发射消耗 40 资金。选中导弹艇使用其舰载弹药，否则使用岸防弹药。飞行 4 秒，命中造成实际损伤；岸防每 45 秒补一枚，最多五枚，导弹艇初始三枚。
- 舰船可花资金建造和维修。运输舰 100、驱逐舰 220、导弹艇 150；维修 60，恢复最多 80 HP。
- 开战 33 秒后朝鲜援军抵达北京（1,200 兵力和导弹艇），66 秒后俄罗斯援军抵达上海（1,800 兵力和驱逐舰）。地图可查看运输路线和剩余时间；到达后陆军向我方大陆部队推进，并参与实际反攻。
- 地图中的俄罗斯、朝鲜是架空战役的大陆支援方；可点击查看状态，地理轮廓保持 Natural Earth 数据。

新版存档使用 `strait-front-v7`，记录国际时间线、待决事件、科研与结局。v3/v4/v5/v6 自动迁移，原自动存档不覆盖。

## 怎么玩

1. 点「进入指挥」→ 左上「护送补给」。自动选中海岚号，再点有黄色标签的补给船持续护航；点敌舰会持续追击，进入射程自动开火。也可以选择「拦截敌舰」，60 秒内击沉两艘敌舰。
2. 「导弹打击」→ 点敌舰，可用 40 资金换取一次实际打击。不保护补给船会失败；成功获得 160 资金、1 枚岸防导弹，前 3 次成功额外给第一军 600 人。
3. 点另一座城市即可改令；「停止 / 驻守」只停止选中的军队。「部队列表」可以选择并定位部队；左下显示名称、兵力或 HP，右下可暂停和停止命令。
4. 「补兵 +500」把预备兵补到选中部队，最多转入 500 人；必须位于我方陆地。「＋ 组建」消耗 250 预备兵，在我方城市组建新军，最多 6 支。
5. 左上「带兵登陆」→「出发，登陆福州」，自动补入最多 500 预备兵并下达首个登陆令。之后点陆军 → 点敌城进攻，点我方城市驻守。右上「发展」可选经济、科技、外交和修复；没有合作前置要求。
6. 同时控制福州、广州、南京获胜。驻守部队会抵抗附近敌军，留下军队守城。空袭会损伤后方部队、运输部队和设施；及时疏散和修复。

部队拥有独立身份、兵力和连续路径，不再按敌方阵营自动合并。行军与渡海保持同一支部队；路线只沿相邻地图格移动，禁止穿越外国陆地。进攻只夺取沿路狭窄通道，抵达目标后停止。

地图使用 Natural Earth 1:50m 真实海岸线和城市坐标，统一经纬度投影，包含太平洋两岸及夏威夷、阿拉斯加。「台海」回到指挥区域，「世界海图」查看合作方。点美国、日本、韩国、菲律宾可洽谈合作；「放大地区地图」查看当地城市。数据来源与许可见 [地图数据说明](docs/map-data.md)。

拖动地图平移，滚轮或 + / − 缩放。空格暂停，暂停时仍能下令；数字键 1–6 选择军队，Esc 取消选择。隐藏网页自动暂停。

1.3 版自动存档使用 `strait-front-v4`，可自动升级到本版 v5，保存每支部队的位置、兵力与尚未完成的命令。v3 地图进度自动迁移，已有军队停在原位置等待新命令；原 v3 存档不覆盖。更旧的 v1/v2 存档仍在首页 1.1 版入口恢复。

## 运行与发布

```sh
npm start
npm test
npm run build
```

本地打开 `http://127.0.0.1:43993/`。无 npm install 步骤；开发脚本需要 Node.js 22+。dist 可直接发布到静态网页托管，不需要服务器、账号或 API key。

固定地图、单人对三个电脑战区，没有多人联机。是否好玩由实际试玩反馈决定，自动测试只能验证规则。

geo-core.js 管理地理战场的领土和兵力；strategy.js 管理筹备与空袭；geo-map-view.js 渲染矢量地图，geography.js 负责统一坐标；app.js / strategy-ui.js 管理交互，marker-layout.js 处理混合单位标签避让，tactical.css 保留基础布局，cel-ui.css 管理赛璐璐界面，battle-art.js 记录图集坐标，geo-map-view.js 按真实战役时间绘制地图与战斗动画。tests/ 与 docs/ 记录规则和验证范围。
