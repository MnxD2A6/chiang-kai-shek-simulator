# 1.8 声光验证记录

日期：2026-10-14。Codex In-app Browser；桌面 1280 × 720，手机视口 390 × 844 / 360 × 740。

## 实际浏览器操作

全部从界面点击完成，没有注入游戏状态或伪造存档。

- 打开声音面板并试听。Web Audio context 为 running；实际解码 WAV 后，输出电平 RMS 测得 0.07483（水花）、0.01383（爆炸）。
- 试听中取消启用音效：当前声源数变为 0，输出电平为 0；900ms 后播放计数保持不变，证明待播放的后续试听已取消。
- 刷新后静音仍关闭，重新开启并把音量从 55 调为 54；之后刷新读到 54，设置保留。
- 继续既有战役，暂停时下令岸防导弹攻击敌舰。暂停时战场无声；恢复后触发发射、真实炮战和击沉声，测得 RMS 0.06646。暂停 400ms 后为 0 声源、0 输出。
- 真实导弹打击福州：显示尾烟、命中火球和余烟，最近播放音效为 explosion；保存命中画面。
- 南港运输舰驶向台北，启用环境声：实际 2 个循环声源（引擎与海面）、RMS 0.02313；暂停后两个声源均停止，电平为 0。
- 手机重载，声音入口、音量滑块、试听按钮和面板完整可见；390 / 360 宽度无横向溢出，360px 时最右侧 header 按钮止于 350px。
- 本地页面未记录控制台 warning / error。
