# 1.9 海峡行动：先打一段可以直接操作的开局

## 问题与本次范围

1.8 新开局只有安全筹备，点敌城会被拒绝，开战入口藏在发展面板。合作给永久数值收益，后续缺少明确行动。本次先补「海战取得补给 → 实际补入部队 → 登陆首城」的小段玩法，不把功能测试当作玩家觉得好玩的证明。

## 实际行为

- 左上直接选择护送补给或拦截敌舰，筹备期即可交火，不触发全面战争的空袭和援军。
- 驱逐舰 / 导弹艇点敌舰会持续追击；护送行动中，选中战斗舰再点补给船会持续跟随护航。点其他海域或停止可取消。
- 两艘敌舰使用真实舰炮、耐久、航线；6 秒反应时间后开火。补给船被击沉则失败，拦截行动 60 秒内未消灭全部敌舰也失败。失败无奖励，可以重试。
- 威胁清除后补给船加速进港，减少收尾等待。成功给予 160 资金、1 枚岸防导弹；前 3 次还会给驻守部队直接补充 600 人并相应增加容量。后续可重复获取资金 / 弹药，兵员奖励有上限。
- 行动结果显示实际发放的部队名称与奖励。登陆按钮说明空袭与援军，点击后补入最多 500 预备兵并命令第一军进攻福州。军队仍可自由改令。
- v6 自动存档使用独立键，读取旧 v3/v4/v5 存档，不覆盖旧自动存档。行动途中恢复时自动定位战区并选中驱逐舰。

## 验证

- 根目录 `npm test`：144 / 144 通过，包含新增 13 项海峡行动与追击测试。覆盖实际伤害、闲置失败、命令改变结果、暂停、奖励上限相关容量、活动 / 旧版存档恢复、无重复奖励、开战收尾和错误动作拒绝。
- 浏览器只通过可见界面操作，没有注入军队、地图、资源或存档。
- 第一场护航：调海岚号持续护航，导弹击沉另一艘袭击艇；补给船靠港后第一军从 600 增至 1,200 人。存档恢复成功。
- 第二场拦截：两艘舰分别追击，导弹集中一号舰；成功消灭两艘敌舰，第一军增至 1,800。海岚号剩 110 HP，流星号剩 28 HP，维修后流星号 108 HP。
- 从同一局直接登陆福州，第一军补入 478 预备兵，福州变为我方，界面显示 1 / 3 和下一目标广州。之后实际点下空袭疏散。
- 390 × 844 浏览器视口：实际点击补给船成功下达持续护航，任务文字、目标、舰艇和命令可见；这不代表物理手机触控或音频设备验收。
- 本地实玩无浏览器 error / warn。截图与运行记录在工作区 `CounteroffensiveFront/qa/gameplay-1.9/`；`mobile-escort.png` 是视口尚未生效的桌面截图，窄屏证据以 `mobile-orders-verified.png` 和 `mobile-runtime.json` 为准。

## 验证边界

本次实玩覆盖开局两种海战与首城登陆，没有把这次实玩称为完整三城战役通关。原完整战役自动回归仍通过。玩家是否觉得这一段更有趣，仍需玩家体验。
