# 城市防卫规则

目标：让导弹、经济与本岛防卫构成有后果的选择，维持简单点选操作。

## 导弹与民生

每轮六枚城市导弹。60资金的疏散只降低人员损失65%，不降低建筑与工厂损伤。每枚漏网导弹造成最多6建筑、10工厂损伤及35应急支出；科技、外交和仍有效的韩国合作提供有限设施加固。台湾民心是独立于国际观感的数值，初始80；空袭与城市失守会损失民心。

实际收入同时受可生产的工厂、建筑完整度和民心影响，再叠加国际贸易与制裁。损伤不会随时间自动消失。点击“发展 → 后方 / 防空”，每城160资金重建，约0.4周后最多恢复24建筑、30工厂与5民心。被占领城市不能新建工程，已有工程需夺回后才能完成。不同城市可以同时维修，经济和科技建设仍可继续。

## 防空

美国防空系统每套900，交付约0.8周，初始附带8发拦截弹。每套每轮自动拦截至多2枚，每次消耗1发；最多两套，因此六枚齐射仍可能漏网。补弹每枚40、每次至多四枚，按实际缺额收费。美国态度需至少+10，无制裁且半岛航路可用；军售受限时待交付合同会等待，已部署系统继续使用现有弹药。

## 反向登陆与结算

开战约0.4周后，大陆预告“收复台湾”行动，优先选择留守兵力较少的城市，再经过约0.6周集结。两艘实际运输舰各搭载900人，配一艘护航驱逐舰，从仍由大陆控制的福州、上海或广州出港。主要港口全部丢失则该轮无法出航。

选我方驱逐舰，再点敌运输舰持续追击，进入射程优先打击选定敌舰。击沉运输舰会取消其搭载的登陆部队；抵达后生成真实陆军，与驻军作战、夺取城市，并继续向本岛其他城市推进。提前把舰队放在必经海域更可靠；临近岸边才从远处追赶可能来不及。登陆部队被消灭后显示防守成功，后续仍可能组织下一轮。

军事胜利需要同时控制福州、广州、南京，保住台北和高雄，并守住一周。台湾两城同时失守时提供0.5周夺回一城的倒计时；民心或设施耗尽也会失败，并明确显示原因。威慑谈判的结局继续保留。

所有时间随1×/2×选择等比例改变；默认每周60真实秒，暂停可下令。
