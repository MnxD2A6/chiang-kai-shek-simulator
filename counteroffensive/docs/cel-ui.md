# 1.6 赛璐璐 UI 与素材

日期：2026-10-14。

按用户指定方向制作：2D 赛璐璐手绘、干净颜色、带时尚感。纸白 #f7f4ed、墨黑 #111318、橙 #ff6b24、警示黄 #ffcd24。保留蒋介石历史照片。

## 生成资源

使用内置 `image_gen.imagegen` 生成四张带真实透明通道的原始 PNG；未使用外部付费 API。完整英文提示词、生成日期、文件尺寸与 SHA-256 记录在 [manifest.json](../assets/ui-cel/manifest.json)。未使用既有游戏的图像、截图或商标。

| 文件 | 尺寸 | 用途 |
| --- | --- | --- |
| motion-speedband.png | 1983 × 793 | 下令提示与移动 / 进攻主命令的黑橙速度带 |
| hazard-warning-wrap.png | 2172 × 724 | 空袭预警周围的黄黑警示条 |
| missile-warning-badge.png | 1254 × 1254 | 导弹命令、空袭提示、飞行导弹旁的警告标志 |
| command-icons-cel-atlas.png | 1536 × 1024 | 3 列 × 2 行命令图集，CSS 裁切使用 |

图集上排为移动、攻击、驻守，下排为陆军、舰队、暂停。目前用于移动、驻守、暂停和舰队列表；攻击与陆军图形保留在素材中。地图最小尺寸的单位继续使用清晰的简化符号与舰船轮廓，避免复杂纹样在缩小时失去辨识度。

文字、兵力、倒计时和按钮交互均由 HTML / Canvas 实时显示，不烘焙进 PNG。素材按原始透明 PNG 保留；没有通过图像编辑脚本重新绘制。

## 接入

- `cel-ui.css` 在原始布局之后加载，负责赛璐璐色彩、倾斜照片、橙色指令带、扁平列表和手机适配。
- `app.js` 根据真实命令结果切换速度带提示，反映真实的选择、暂停和移动状态。
- `geo-map-view.js` 绘制扁平地图色彩、橙色路径与导弹旁的警告图形。
- 所有图片均为相对路径，根项目与独立游戏构建都会包含。可以直接发布 GitHub Pages。
- 战役规则和 v5 存档格式沿用原版。

照片、地图数据的各自许可继续适用，见 `portrait-photo.md` 与 `map-data.md`。生成素材随本仓库提供用于本游戏的修改与再发布；本页不承诺生成图像的独占性或特定法域下的版权状态。
