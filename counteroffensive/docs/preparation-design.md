# 筹备与不对称战局，1.1

用户认可基础版，要求增加较可信的实力差距和开战前的其他发展路径，同时保持操作简单。

采用纯游戏化的经济、技术、支援和基础设施数值，不模拟现实武器参数或现实行动方案。大陆全部由三个守军战区控制，合计兵力显著多于开局玩家。筹备期和平，不必抢倒计时，玩家自行开战；点击地图不会意外宣战。

三条发展路线各三级，共用资金并同时只能进行一项工程，约 12 秒完成。经济提高持续收入和人口容量；科技降低进攻损耗、增加防护；外交提供一次援助和更长的空袭间隔。每级成本、工期、效果在按钮上直接显示，不设隐藏前置条件。战时仍可发展或花资金修复基础设施。

开战后有预警倒计时、导弹航迹和影响。打击减少驻军、舰载兵力和基础设施；基础设施下降影响收入及补充，归零失败。技术和外交降低损失；预警时可消耗资金疏散，进一步减少本轮损失。没有无提示的开局死亡。保留 20% 大陆控制胜利。

strategy.js 管理经济、升级、开战、预警、损伤和存档验证；core.js 继续管理兵力、实际领土和运输舰。strategy-ui.js 负责筹备面板、预警条和帮助文字。原版存档继续使用原规则，新局默认筹备模式，独立 v2 自动存档保留 v1 数据。
