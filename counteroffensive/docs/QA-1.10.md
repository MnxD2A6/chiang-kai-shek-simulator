# 1.10 世界危机与事件插图

## 实际变化

- 国际面板只有新闻、关系、机密三个页签。重大新闻自动暂停，2–3 项回应均显示费用与后果，每条至少一个免费选项。后续按战役时间排程，30 秒代表一个游戏周。
- 34 个剧情节点、85 项回应：半岛猜拳危机、欧洲复活风波、俄罗斯机甲与劳动争端、巨型黄鸭堵港、月球电台、企鹅大使、救援、记者会、贸易与曙光计划。故事并非一局全部出现；舆论和贸易事件可以继续循环。
- 34 个节点各有独立原创 PNG，包括调查、后续和结局事件。复古手绘海报风：红黑旧纸色、粗笔触、石版画颗粒。插图按当前事件加载；参考原图不随网站发布。原始图片、完整提示词与 SHA256 在 `assets/event-posters/manifest.json`。
- 舆论、国家态度与制裁影响收入、有效合作和预备兵容量；半岛战争牵制美韩支援，友好关系可阻止尚未抵达的俄朝援军。机甲与国际干预成为地图上的真实战斗单位。
- 秘密科研采用抽象进度、经费和风险，支持稳步、加速和暂停。怀疑、调查、最后通牒有不同的回应；冻结保留主要进度，外交可以修复关系。没有现实制造或规避监测的技术内容。
- 完成后可保留、公开威慑、谈判结束本局或实际使用。实际使用需要二次确认，消耗唯一储备，引发制裁、撤援和干预舰队，战役继续，失去未使用储备的停火结局。
- v7 独立自动存档，兼容 v3–v6 迁移，原自动存档键保留。待决事件连同暂停状态保存，重复点击不会重复奖励。

## 验证证据

- 根目录 `npm test`：162 / 162 通过。包含 18 项国际规则及插图完整性测试，以及原有战役、舰船、操作、存档与旧游戏回归。新插图逐一验证 PNG 尺寸 1536×1024、34 个不同哈希与事件覆盖。
- 独立游戏和根目录 `npm run build` 均通过，零新增运行时依赖。
- 浏览器通过可见按钮连续游玩，没有注入资源、进度或伪造存档。实际处理半岛战争与停战、科研质询、冻结后恢复研发、机甲通讯与登陆、欧洲风波、企鹅倡议。
- 同一自然游玩流程 02:24 完成科研，公开威慑并谈判，于 03:18 选择“威慑下的停火”结束本局。
- 通过游戏“导出 JSON”保留真实科研完成存档，再通过“导入存档”恢复，选择保留后实际使用。验证二次确认、严重后果新闻、游戏继续，以及地图出现“国际干预1号 / 2号 / 3号”。
- 刷新待决新闻并“继续上次战役”，恢复相同新闻、时间与暂停状态。桌面插图与三个回应同屏可见。
- 390×844 浏览器视口：实际测量页面宽390、对话框宽370，无横向溢出；插图加载、三项回应和底部按钮同屏可见，免费回应可点击。此项不代表物理手机或音频设备验收。
- 一次独立只读代码审查发现三个 P2：循环新闻耗尽、拦截误算护航、重复谈判空扣款。均增加失败复现测试并修复，完整回归通过。长期自然筹备/科研规则模拟的 v7 多次编解码有效。

本地实玩截图和运行记录保留在工作区 `CounteroffensiveFront/qa/world-1.10/`。部署结果与线上截图另外记录在该目录；本文件的构建与实玩验证不替代发布后的公网检查。

## 验证边界

本次实际走通科研停火结局和实际使用后的干预，不宣称人工走遍85个选项或全三城军事通关。新事件的完整分支由规则测试覆盖。玩家是否喜欢节奏与画风，仍需玩家体验。
