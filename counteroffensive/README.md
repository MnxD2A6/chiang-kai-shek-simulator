- 发展和国际面板显示持续影响、剩余保障与下一步；免费收尾不再产生虚构退款。
- [全部路线与后续规则](docs/development-2.6.md)。旧实时进度可继续，比较新路线建议新开一局。

## 战前发展与国际事件

先投资经济、科技或外交到1级，并保留项目预算，对应筹备议题就有机会出现。每条事件链选一条路线，在发展面板查看条件；达标并等待一段筹备时间后，从后续新闻中兑现收益。钱不够可免费“稍后再议”，之后在议程中“重新洽谈”。

日本产线可选出口收益或城市加固；防空合作可选联合预警或本地抢修；俄方机甲争议可选延迟军援或公开检修。出口受贸易状态影响，联合预警需要合作与军售条件，也会让秘密科研从8%风险开始。开战中止未兑现项目，投入不返还，已完成收益继续生效。

## 简单指挥

点军队，再点城市：我方城市为移动驻守，敌方城市为自动进攻。点舰船，再点海域移动或敌舰追击；进入射程自动开火。运输舰靠近陆军自动载运，每舰运一军。

“发展”投入经济、科技、外交，一次进行一项。预备兵自动积累，点选军队按“补兵”转入部队。准备好后“准备登陆”，控制三城并守满一周，抵御两轮城市空袭、击退两次登陆，同时保住台北、高雄才能军事胜利。民心或设施归零会失败，台湾两城同时失守时提供夺回倒计时。

秘密科研只包含抽象预算、进度、风险和投入档位。成果公开且未实际使用，可通过后续谈判威慑停火。实际使用会导致制裁、撤援和干预舰队，不会直接获胜。

## 城市、防空与反登陆

疏散只保护人员，导弹仍会损伤建筑与工厂、扣民心和应急资金，并持续压低收入。“发展 → 后方 / 防空”可查看逐城损伤与最近袭击报告，每城160资金重建，需0.4周。

美国防空每套900，需0.8周交付、附带8发弹药；每套每轮至多拦截2枚，最多两套。拦截弹每枚40，按缺额补充，每次至多四枚。军售需要美国态度至少+10、没有制裁且半岛航路可用。

大陆会公告“收复台湾”作战，实际派出两艘900人运输舰及护航舰。提前部署舰队，点驱逐舰再点敌运输舰拦截；漏网部队会在台湾上岸作战、夺城。保留驻军，避免只顾向大陆进攻。[完整规则](docs/homefront-2.2-rules.md)。

## 时间与随机事件

默认一周约60秒，进度条显示本周推进与距下周时间，可切换2倍速。暂停、重大新闻、菜单或切换网页都会冻结模拟，筹备没有周数截止线。游戏内一周为30模拟秒，默认每真实秒推进0.5模拟秒；移动、科研、收入和威胁一并放慢，保留原数值比例。工程为0.4周。

72个事件、176项回应，使用34张手绘插图；新增故事复用相关海报。开局从满足前提的起始故事随机抽取，不再固定猜拳。开场、后续和下一条故事的出现时间带随机变化；选择仍决定后续分支。随机数和已排定事件写入存档，旧v7进度保留原先排程。新故事每局至多抽取一次开头，更多内容会随不同开局与长期筹备逐步出现。

## 大陆动态

大陆先预告，再于6–12模拟秒后落实行动。右侧显示警戒、态势和倒计时，“查看部署”可定位地图。

| 当前局势 | 实际回应 |
| --- | --- |
| 扩军或增建舰艇 | 沿海新增650人守备队，已有部队可以补充 |
| 已达成国际合作 | 美国态度−6、日本态度−4，可能影响支援 |
| 科研风险上升 | 未公开项目暴露风险+6 |
| 经济发展 | 一次性流失最多40资金的订单 |
| 战时尚未登陆 | 出动可见的沿海巡防舰 |
| 陆军已进入大陆 | 派900人反击纵队，按实际地图路线进攻 |
| 较平静 | 暂缓升级，地区紧张−3 |

筹备期花50资金沟通，可取消本轮待执行部署、紧张−8并延后下一轮反应；冷却一周，已有部队保留。警戒受到兵力、合作、科研风险、战争与短期缓和影响。上述行为与数值均为架空游戏规则。

右侧同时显示美、日、韩、菲、俄、朝态度与真实支援状态；点国家进入详情。手机通过“各国状态”展开，避免长期遮挡地图。
