# 地理地图改造 1.2

用户要求：美国、日本、台湾的位置与轮廓更准确，放大后能看清城市与军队。

采用 Natural Earth 1:50m 海岸线及城市坐标，本地打包，不依赖在线瓦片服务。全图以太平洋为中心，使用统一 Mercator 经纬度投影，美国跨日期变更线放在右侧，包含阿拉斯加和夏威夷。默认镜头聚焦台海，可一键切全图、台海，并平移缩放。

渲染世界与模拟分辨率分开：全球底图为矢量海岸线；战场栅格覆盖大陆与台湾，栅格与矢量使用同一投影。城市显示使用真实坐标，出兵落点吸附邻近有效陆地。城市和军队在屏幕上保持可读尺寸，根据缩放与碰撞检测显示文字。军队显示当前兵力和目标连线，点击军队可以聚焦；加入比例尺、经纬网。

旧战役保留在 legacy/，继续使用原规则与存档键。新版独立 v3 存档；导入旧文件时提示到旧版恢复，不把旧领土任意映射到新海岸。玩法保持筹备、合作、开战、登陆、领土推进。

## 执行计划（主代理直接实施）

1. geography-data.js 保存生成后的矢量轮廓、城市和战场掩码；scripts/generate-geography.py 可从原始公开数据复现。记录来源和哈希。
2. geography.js 提供统一投影、逆投影、城市落点和静态地形；geo-core.js 复用既有战斗规则并适配大陆掩码及坐标。
3. geo-map-view.js 提供矢量底图、缩放层级、标签避让、军队兵力标记、比例尺与镜头预设；app.js 接入镜头、合作地点和版本隔离。
4. tests/geography.test.cjs 验证日期线、城市位置、真实海陆路径、战斗推进、新版存档和完整获胜流程；保留旧规则回归。
5. 浏览器实测全图/台海/城市近景、舰队及军队、存档、窄屏；构建后发布并验证公开文件。

边界：跨日期线不得连出横跨整图的假陆地；海岸不得与落点错位；全图和近景按钮点击区与渲染必须一致；缩放和平移不能遮住城市操作；旧存档不能被覆盖；实体手机未测不记为通过。
