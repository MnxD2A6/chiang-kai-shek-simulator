# 2.8 民心危机与党派协商

用户同意加入民心、岛内局势及大陆对困境的回应，并要求加入国民党与民进党对抗。沿用实时地图与两三项回应，不增加选举操作或新的主界面。政坛为跨时代架空，协调值表示本局协商关系，不是现实选票或真实党派立场。

国民党内有安全、地方与民生分歧，民进党会质询采购与战争代价，也可参与防卫和救灾。两方协调值独立变化，不是零和选票。任一低于25，实际收入减10%。预算协作可让两周收入加8%、新重建工程快2模拟秒；提前动用100或80资金则让未来三周收入减15%。已开工工程保持原完成时间。

民心低于40时，先给一周预警，再出现罢工、抗议或外迁议题。罢工实际收入减18%；抗议收入减15%、每周民心减1。影响最多持续两周，可用新闻回应或救济提前结束。民心归零给一整周补救时间；暂停和新闻阅读暂停计时，存档不会重置倒计时。零民心不能在宽限期抢先达成胜利。基础设施或城市实际失守仍按各自规则结算并说明原因。

「发展 → 后方 / 防空」增加民心与协商卡。民生救济90资金：民心加12、两党协调各加6、解除生产扰动，每周一次。两党协商60资金：民心加4、协调各加12、两周预算协作，每两周一次。当前新闻必须先回应；资金不足、重复操作或战役结束时拒绝扣费。

十二个岛内事件均有三个回应、至少一个免费选项和自己的复古手绘插图：预算、国民党内部争论、民进党质询、联合救灾、战争问责、罢工、抗议、轮渡外迁、大陆民生物资、美国援助条件、核后听证、重建回访。城市真的受袭、核武真的使用后才出现相关问责；美国附加要求需已有合作或采购。大陆在筹备期观察到低民心后，先公告，再送来附带外交代价的物资与降温提案。

玩家可以在轮渡事件中允许民众自愿赴大陆临时暂避：民心加4、国际观感加4，两周收入减12%，记录一批外迁安排。也能花钱作岛内安置或留居救济。个人迁移不改变城市所属，不把外迁人数当作党派支持；尚未选择外迁就不产生外迁批次。

v14独立保存协调、民心预警、生产扰动、外迁安排和一次次回应，兼容v13与更早实时进度；已结束的旧战果保持原样。当前八类主线收官与九条路线尾声保留。归档六角格入口不接入这套民心与党派机制。
