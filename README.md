# 蒋介石模拟器 · 另一条时间线

亲自带队跨桥、护送粮车、守住村庄。融合 **2D 即时部队指挥、自由探索、人物互动和电话剧情** 的中文网页小游戏；另有十二回合经典经营模式。

纯 HTML / CSS / JavaScript；无运行时依赖、无注册、无 API key、无付费生成。代码、地图、像素绘制和程序音效以 MIT 许可发布。

**在线试玩：[打开游戏](https://mnxd2a6.github.io/chiang-kai-shek-simulator/)**。无需登录或下载。第一次进入建议点击「先指挥第一场战斗」。

源码仓库：[MnxD2A6/chiang-kai-shek-simulator](https://github.com/MnxD2A6/chiang-kai-shek-simulator)。推送至 main 后，GitHub Actions 自动运行测试并部署 GitHub Pages。

## v2.0：先直接指挥，再慢慢探索

默认「前线冒险」没有行动点，也不需要调财政或研究战力公式。只需：

1. 点部队卡片或蓝色部队，选中队伍。
2. 点地面移动；点红色敌军交战。步兵、机枪和炮兵会在射程内自动开火。
3. 按空格或「暂停下令」，暂停时仍能安排命令，再继续战斗。

第一场要跨桥占住东岸旗帜 6 秒；第二场保护粮车，选部队后点「护送粮车」会持续跟随；第三场在村口附近守住 50 秒。部队实际沿路线移动，河流需要绕行桥面，掩体减少受到的伤害。原地驻守停止移动，撤回集结点退到开战位置。失败可重试，已完成战果保留。已完成战斗可以练习，不重复发奖励。

**五个可走动场景**：作战室、军营庭院、铁路补给站、河边村庄、前线指挥所。WASD / 方向键移动，E 交谈；也能点击地面寻路、点击人物走过去交谈，或使用手机方向键。出口相互连接，上方场景标签可直接前往。

**十一位人物**各有三个对话分支和随阶段变化的开场。训练会提高下一场部队能力，休息提高士气，补给站可领取物资。可选药箱支线：找仓管领取药箱 → 去村庄交给林医生 → 每场战斗加入自动救护附近受伤部队的救护队。

**七条电话线路**：陈诚、宋美龄、何仓管、林医生、李营长、老周和接线员小林。每条可问战况、问操作、聊近况、请求帮助。战斗中呼叫的步兵会到场，救护车恢复存活部队生命，弹药补给实际增加弹药。问话免费，支援费用和阶段限制写在按钮旁。通话时战斗自动暂停，挂断后恢复此前暂停状态。

「前线冒险」与「经典经营」分别保存。旧版经典存档保留，从顶部「经典十二回合经营」进入。前线自动保存已完成战斗、人物互动、支线、资源和位置，支持独立 JSON 导入/导出；刷新后当前未结算战斗重新集结。暂回指挥所而不刷新，可以保留现场继续。

所有对白、任务、地图与部队均为架空创作，没有真实人物语音、AI API 或真实电话服务。

## v1.1：先学会第一回合

启动页点 **先玩第一回合教学**。参谋会按你的实际操作推进，告诉你点哪里、为什么：

1. 接起电话，选择一项免费事件决定。
2. 点击地图桌自动走过去，或按 W / ↑ 走近后按 E；也能直接打开战略图。
3. 选择重庆，发展工业两次，完成后方建设任务。
4. 结束回合，看资源怎么变化、任务奖励是否到达、下一轮哪里有风险。

教学可跳过，也可以从“带我学第一回合”再次进入。首轮进行中刷新并继续存档，会保留教学进度。地图上的命令直接显示效果与成本，无需悬停。作战室与地图是两个主视图，人物和地板均可点击；走路会绕开家具。

每轮都有具体任务。完成后获得国库 12、粮秣 8、民心 3；未完成仍可继续。每座城市最多三次工业建设，总工业最高 20。

**施政方针**持续生效：守势提供 8 战力但每轮多支出 8 国库；动员每轮军备 +5、粮秣多消耗 4、民心 −4；民生每轮民心 +4、粮秣产出 +3、国库多支出 10。更换花费 8 国库与一个行动，每轮最多一次。

**顾问信任**初值 50，每次电话请求增加 7；每位联系人每轮接受一次请求。信任达到 75 后，军事/外交/财政/后勤/总机分别追加军备 3、外交 3、国库 4、粮秣 4、民心 2。低军备、高通胀、低粮秣、低民心会影响相关顾问信任。对白会根据当前战况与资源变化。

v1.1 新开局的最佳和解结局还要求完成至少 7 项任务。v1.0 存档能继续，过去未记录的任务不追溯要求；旧版发行包会单独保留。

## 立刻玩

推荐用本地服务器开始游戏并获得稳定的存档来源：安装 Node.js 22 或更高版本，然后在此目录运行：

```sh
npm start
```

浏览器打开 `http://127.0.0.1:43891/`。没有 npm install 步骤。可通过环境变量 `PORT` 选择其他端口。

代码也采用经典 script 标签，可尝试在支持本地网页的浏览器中双击 `index.html`。当前完整试玩验证使用 HTTP；内置浏览器的安全策略不允许打开 `file:` 地址，因此未验证双击方式。

## 怎么玩

- **作战室**：WASD / 方向键移动，E 互动；鼠标点击顾问、电话也可以互动。手机提供方向键与互动按钮。
- **接电话**：左侧总机每轮来电，接起听筒选择本轮决策；也能直接在右侧电报区选择。事件不消耗行动点。
- **打电话**：拨给陈诚、宋美龄、财政办公室、运输办公室，选择一个请求；主动请求消耗 1 行动和显示的资源。查看对白或挂断不消耗资源。所有对白为架空。
- **地图**：点击城市，下达守备、工业、筹粮、民生、财政或外交命令。已失守城市可组织反攻；反攻具有随机结果。
- **结束回合**：处理电报后可以推进；最多三次行动，不必用满。结算战况、财政和粮秣，进入下一次来电。
- **戏剧模式**：默认开启，可随时关闭；加入单独标识的架空幽默选项与总机闲聊。
- **存档**：每次操作自动保存到 localStorage，也能导出、导入 JSON。重新开始需要确认。浏览器和网址改变后本地存档互不共享，导出文件可转移。

## 策略与结局

12 回合选取 1936–1949 的关键时间节点，每轮并非固定月数。九座城市各有守备、民生与收入。

**战力** = 城市守备 × 0.58 + 军备 × 0.34 + 城市民生 × 0.1 + 粮秣修正（粮秣至少 20 时 +9，否则 −9），四舍五入。达到本轮压力即可守住。预告会随行动与事件更新，战斗按实际预告结算。

**国库净收入** = 控制城市收入 + 工业 × 2 − 20 − floor(通胀 / 12)。**粮秣净产出** = 8 + 工业 + 外交援助 − 12 − floor(军备 / 18)。1941 年节点起，外交达到 50 可获得 floor(外交 / 10) 粮秣援助和 2 军备。

开局发展工业可积累长期回报。危城修筑工事，低粮及时筹粮。发行公债缓解财政但增加通胀；通胀达到 50 会每轮扣民心。粮食以本轮生产和消耗后是否不足判定；恰好归零但足够供给本轮，不算断粮。

到终章有 **未曾发生的和解、艰难的重建、退守与余烬、摇晃的平衡**；民心归零、控制城市不超过一座、连续两轮断粮会出现提前结束的 **失序的指挥桌**。1945 年节点结算时恢复失守城市管理，随后进入战后抉择。战后协商可以降低后续战线压力。

所有数值均为玩法设计，不代表真实财政、部队、疆界或历史因果。

## 上传 GitHub 并上线

将本目录的内容作为一个**独立仓库的根目录**上传，例如仓库名 `chiang-kai-shek-simulator`。不要把 ZIP 本身作为唯一文件上传，也不要上传其他工作室项目。

最简单的免构建发布：

1. 创建 GitHub 仓库并上传本目录文件（含 `index.html`、脚本、样式、`assets/`）。
2. 在仓库 **Settings → Pages → Build and deployment** 选择 **Deploy from a branch**。
3. 选择 `main`（或你的主分支）与 `/(root)`，保存。
4. Pages 完成部署后，使用页面展示的网址打开游戏。仓库子路径由相对资源路径支持。

也可使用已附带的 Actions 自动测试发布：

1. 在 **Settings → Pages** 把 Source 改成 **GitHub Actions**。
2. 确保 `.github/workflows/pages.yml` 在仓库中，然后推送到 `main` / `master` 或手动运行该工作流。
3. 工作流会运行测试、构建 `dist/`、上传 Pages artifact、部署网页。

两种发布方式选择一种即可。静态项目无需构建也能发布；Actions 的 `dist/` 只打包游戏文件。项目当前交付是本地发布就绪版本，不表示已创建远程仓库或已上线。

命令行上传前可以在本目录初始化独立仓库（如尚未初始化），然后按 GitHub 新仓库页面提供的命令关联远程：

```sh
git init -b main
git add .
git commit -m "feat: playable 2D alternate-history simulator"
# 随后添加你创建的远程仓库，并 push main
```

工作流参考 [GitHub 官方 Pages 文档](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。公开仓库在 GitHub Free 可使用 Pages；私有仓库可用性依账号计划而定。

## 历史背景与创作边界

这是一个有明确主角的架空历史游戏。历史人物并不自动代表认同；对白、策略选项、数值、地图、虚构电话和所有结局都是本项目创作。战争受害者不作为笑料。历史年份与背景仅作框架，事件选项不应视为人物实际言行或历史教学材料。

背景参考：

- [美国国务院历史办公室：1937–1941 中日战争与国际关系](https://history.state.gov/milestones/1937-1945/pearl-harbor)
- [美国国务院历史办公室：1945–1949 战后与内战](https://history.state.gov/milestones/1945-1952/chinese-rev)
- [美国国家档案馆：1942–1945 中缅印战区档案](https://www.archives.gov/research/guide-fed-records/groups/493.html/1000)
- [中国政府网：近代史（西安事变与抗战背景）](https://www.gov.cn/guoqing/2021-04/09/content_5555766.htm)
- [美国国务院历史办公室：1943 年开罗会议公报原件](https://history.state.gov/historicaldocuments/frus1943China/d136)

仅参考背景，未复制档案图片、录音或文章；像素素材和地图由代码原创绘制。
