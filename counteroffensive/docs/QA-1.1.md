# 1.1 筹备与太平洋地图验证

2026-10-13，Windows 本机 Node.js 与浏览器。所有战争数值为架空游戏平衡设定。

- 根仓库测试 87 项通过：60 项旧游戏回归、15 项基础领土规则、12 项筹备与新地图测试。
- 规则覆盖工程成本/工期/暂停、主动开战、空袭损失与疏散、修复、合作效果、终局禁用、坏存档拒绝、旧 176×124 地图的领土及舰队坐标迁移。
- 不修改兵力或领土的模拟流程：直接开战在 126 秒因设施归零失败；经济 3 / 科技 3 / 外交 1 获胜，科技 3 / 外交 3 也能获胜。这仅证明可完成的规则路径，不代表玩家觉得好玩。
- 浏览器真实操作：经济与科技各升三级，点击日本达成贸易合作（收入 13 → 15/秒），点击美国取得援助；主动开战、点击福州登陆、前线推进、预警期间暂停并疏散、设施受损后付费修复。
- 同一浏览器战役最终控制大陆 20.0%，共 2,350 格土地，实际开战约 2 分 4 秒后获胜。局内总时长 15:52 包含开发期间停留的筹备时间，不应作为正常游戏时长。没有通过页面脚本注入游戏状态。
- 战果 JSON 通过下载按钮导出，再用文件选择器导入，恢复胜利状态、领土、驻军及合作状态。浏览器重新加载也恢复了扩图前的筹备存档。
- 390×844 窄屏查看全图并实际点击菲律宾，合作说明及按钮可见；桌面恢复 1280×720。未在实体手机测试。
- 浏览器控制台未观察到 warning/error。证据截图保留在本地独立项目 qa/v1.1/，不进入公开构建。

地图为 280×160 非等比例太平洋示意图；美国、日本、韩国、菲律宾提供游戏化合作，不参战。单人对三个电脑战区，无联机。保留旧游戏首页与基础版存档规则。
