## 运行反馈

- 可点击单位仍使用有名称和键盘焦点的 HTML 按钮，Canvas 绘制透明角色 / 舰体，取消方块底座。
- 桌面单位占用 60px 避让区域，手机 52px。姓名标牌、城市、HUD 一起参与避让；空间不足时隐藏图标，通过列表选择。
- 行军四帧、船体微动、航迹尾流由实际战役时间驱动。暂停会冻结这些动画。
- 自动炮战从真实舰船射击冷却变化读取炮口与曳光，命中、拦截、击沉从真实战斗事件读取爆炸。视觉效果不改变伤害和兵力。
- 导弹使用真实发射轨迹，领土变化与空袭命中附带冲击效果。
- 世界地图隐藏近战单位和大型爆炸，保留战略运输线与地区入口。
- 减少动态效果设置会关闭行军换帧、尾流运动和曳光，保留静态命中提示。

港口和云图形保留在图集内用于后续扩展。本版运行时使用山脉、树林、城市、海浪，不把港口图形当作新增可操作城市。

照片与地图许可继续分别见 `portrait-photo.md` 与 `map-data.md`。
