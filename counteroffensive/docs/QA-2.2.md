## 实际浏览器操作

从新战役正常点选建设经济三级，处理随机新闻，积累资金后支付900购买一套美国防空系统，并等待交付。没有注入游戏状态、修改导出文件、加速模拟时钟或回滚袭击。通过可见的2倍速按钮推进时间，暂停时安排命令。

| 阶段 | 实际结果 |
| --- | --- |
| 开战与预告 | 大陆宣布“收复台湾”作战，预告目标高雄与舰队出港时间 |
| 空袭前 | 花60疏散，收入14.3资金/秒，设施与工厂完好 |
| 第一次城市袭击 | 6枚来袭，拦截2枚、命中4枚；拦截弹8→6 |
| 袭击代价 | 高雄建筑100→76、工厂100→60、台湾民心80→73.4；应急支出140、兵员损失333；收入14.3→11.1277/秒 |
| 重建 | 支付160，等待12模拟秒；建筑76→100、工厂60→90、民心73.4→78.4；收入恢复到13.6182/秒，仍低于原值 |
| 大陆登陆 | 两艘900人运输舰有实际路线；本次追击较晚，部队上岸与高雄留守军交战。导出中可见两支剩余626.61人的登陆纵队 |
| 补弹 | 缺两枚时支付80，弹药6→8；弹仓已满后按钮禁用 |

袭击后的真实导出时刻为201.82325模拟秒，重建与登陆后的导出时刻为216.41035模拟秒。它们均通过当前解码器复核。额外重新载入用于验证UI与继续存档；没有用来改写上述袭击结果。

桌面默认尺寸和390×844手机尺寸检查了后方页、维修与采购控件、弹仓状态、面板内暂停按钮。控制台没有错误或警告。

## 规则模拟与实际游玩的区分

指令模拟中，种子2、5、12、40通过经济、科技、外交、两套防空、五支陆军、运输和护航调动获得军事胜利，守住台湾并控制目标一周；共进行744次存档复核。这是规则层的可行路线，不能等同于四局人类实玩或完整平衡性结论。本轮浏览器实玩重点验证袭击、重建和反登陆，没有声称打完一局军事胜利。

在线发布的工作流结果、提交字节比对和公开页面复测在部署后另行核对；本页不将本地构建冒充网站已上线。
