# 渡海 · 反攻大陆：第一版

日期：2026-10-13。用户要求重新制作，以反攻大陆为主题，先做简单的指挥军队，类似 OpenFront。此前 v3 被用户否定、v4 重做被叫停，均保留，不接续旧战斗。

## 核心

原创单人网页实时领土战略。地图是简化的大陆、台湾和海峡：玩家从台湾出发，点击海岸自动派运输舰，点击与己方有接壤的土地向该阵营持续推进。地块实际改变归属，己方驻军、出征军、舰载兵力独立记录。投入的兵力有限，战损永久扣除，余部可以撤回。

兵力自动增长，领土提高兵力上限，城市提高增长率。比例只有 25%、50%、75%；默认 50%。三个电脑阵营在前线扩张、攻击较弱邻居，并可渡海反攻。开场给玩家登陆窗口，随后持续交战。目标控制大陆 20% 的土地，城市提供补兵奖励；失去全部据点且无舰队/可恢复兵力则失败。

界面围绕全屏地图：兵力、目标进度、比例、撤军、暂停；上下文说明直接显示能否攻击、登陆舰何时到、出征兵力。点击任意敌方国土，若已接壤会从实际前线向点击方向推进；未接壤且不靠海则提示先登陆。支持拖动地图、滚轮/按钮缩放、触控点选，隐藏后台自动暂停。独立自动存档、导出与校验导入。

原创实现、程序生成地图，无付费生成、运行依赖、账号或服务端。OpenFront 的官方仓库仅作为实时领土争夺/持续出兵机制的参考，没有复制代码、素材、商标。地图、势力与战争为架空游戏设定。

## Implementation Plan

执行方式：主代理在本会话实施；无需子代理。

1. core.js：纯状态机。先写失败测试，再实现地图与地形、海路、实际兵力扣除、持续地块占领、电脑前线、撤军、存档与胜败。
2. map-view.js：Canvas 地形/归属缓存、实际舰队和航线、前线箭头、城标、地块闪烁；app.js 负责点选/拖动/缩放、短引导、暂停、存档。styles.css 为地图游戏界面。
3. 浏览器验证真实登陆、扩张、对敌进攻、兵力变化、撤军、AI 反攻、存档恢复、窄屏、胜败；性能/模型证据不能替代用户的好玩评价。
4. 独立发行包；沿用此前已授权的公共 Pages，使用 counteroffensive/ 子路径，旧首页保留；发布前测试/build，发布后检查匿名内容与真实界面。

第一版范围：单人电脑对手、固定原创示意地图、简化兵力与登陆舰。没有多人联机、外交、建造、复杂舰种或旧版人物/电话系统。
