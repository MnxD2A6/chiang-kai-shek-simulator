# 渡海 · 反攻大陆 1.2

原创单人实时领土战略。新版先筹备实力，再由玩家决定开战时机；大陆由三个兵力占优的守军战区控制。经济、科技与外交可以组合发展，开战后会出现预警、空袭损伤和修复选择。目标是控制大陆 20% 的土地。

这是一个独立的新游戏，旧蒋介石模拟器和未完成的战斗重做草稿保留。底图使用真实地理数据，阵营与战役为架空游戏设定。

[直接试玩，无需登录](https://mnxd2a6.github.io/chiang-kai-shek-simulator/counteroffensive/)

## 怎么玩

1. 点「开始筹备」，先点经济建设。资金自动增长，每项工程 12 秒，只能同时进行一项。
2. 自由组合三条路线。入门建议经济 2–3 级、科技 2–3 级，再争取一级外交支援；也可以走科技与外交路线。
3. 等兵力积累后点「决定开战」。提前开战没有硬性锁定，但损失风险高。
4. 点福州海岸，自动派出默认 50% 的驻军；登陆后点击敌方土地，从接壤的前线逐格推进。再次点击可增援。
5. 空袭预警出现后，可花 60 资金紧急疏散，降低本轮损失。右上「发展」可继续升级，或花 100 资金修复 25 点基础设施。
6. 占住大陆 20% 获胜。全部据点失守、无运输舰可恢复据点，或基础设施归零则失败。

| 每次升级 | 实际效果 |
| --- | --- |
| 经济建设 | 基础收入 +3/秒，兵力上限 +1,800，补兵 +12/秒 |
| 科技研发 | 空袭减伤增加 22 个百分点，进攻损耗降低 18 个百分点，供养上限 +700，驻军防守加强 |
| 外交支援 | 立即援军 +700，上限 +1,200，补兵 +10/秒，空袭间隔 +18 秒，减伤增加 4 个百分点 |

每条路线三级，升级分别花费 80 / 140 / 200 资金。基础设施受损会降低收入和战时补兵。援军受实际兵力上限约束。空袭伤害针对后方驻军、运输舰和基础设施。所有效果均来自本局游戏状态，不对应现实军事参数。

地图使用 Natural Earth 1:50m 真实海岸线和城市坐标，统一经纬度投影，包含太平洋两岸及夏威夷、阿拉斯加。默认聚焦台海；「太平洋全图」查看整个战区，「台海」返回指挥视角。滚轮以鼠标所在位置缩放，+ / − 可放大至 38 倍；点击我方城市或交战列表可聚焦。放大后显示城市、驻军和陆军/舰队兵力，标签保持可读尺寸并避让。

点美国、日本、韩国、菲律宾洽谈合作；合作面板的「放大地区地图」可查看当地城市。美国提供一次援助，日本提高经贸收入，韩国提供技术加成，菲律宾增加预警时间。合作共用资金和工程队列，每个伙伴仅领取一次。

海岸线来自公开地理数据，精度适合区域战略游戏，不包含街道。数据来源、处理与许可见 [地图数据说明](docs/map-data.md)。

鼠标拖动或手机单指拖动平移；滚轮或 + / − 缩放；⌖ 恢复全图。空格暂停，暂停时仍可下令，但工程与空袭计时同样停止。撤回余部回收尚存兵力，扣 10% 撤退损耗；战损不返还。隐藏网页自动暂停。

新版使用 `strait-front-v3` 独立自动存档。首页「继续旧地图存档（1.1版）」保留完整旧版地图和 v1/v2 规则，原存档键不被覆盖。旧 JSON 请在旧版入口导入，新版 JSON 可在新版恢复。

## 运行与发布

```sh
npm start
npm test
npm run build
```

本地打开 `http://127.0.0.1:43993/`。无 npm install 步骤；开发脚本需要 Node.js 22+。dist 可直接发布到静态网页托管，不需要服务器、账号或 API key。

固定地图、单人对三个电脑战区，没有多人联机。是否好玩由实际试玩反馈决定，自动测试只能验证规则。

## 参考与许可

玩法方向参考 [OpenFront 官方仓库](https://github.com/openfrontio/OpenFrontIO) 的实时领土控制、持续出兵与登陆机制。本项目代码、地图、界面与程序音效独立原创，没有使用 OpenFront 的源代码、素材或商标；以 MIT 许可发布，无付费资产生成。

geo-core.js 管理地理战场的领土和兵力；strategy.js 管理筹备与空袭；geo-map-view.js 渲染矢量地图，geography.js 负责统一坐标；app.js / strategy-ui.js 管理交互。tests/ 与 docs/ 记录规则和验证范围。
