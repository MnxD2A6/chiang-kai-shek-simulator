# 渡海 · 反攻大陆

原创单人实时领土战略网页游戏。点击海岸派登陆舰，点击接壤的土地投入兵力，前线会持续逐格推进。兵力自动增长，土地提高上限，城市提高增长率；三个电脑阵营会扩张、反扑和渡海攻击后方。目标是控制大陆 20% 的土地；福州、南京、广州等城市会加速补兵。

这是一个独立的新游戏，旧蒋介石模拟器和未完成的战斗重做草稿保留。所有地图、阵营、战役为架空游戏设定。

[直接试玩，无需登录](https://mnxd2a6.github.io/chiang-kai-shek-simulator/counteroffensive/)

## 怎么玩

1. 点击开始远征，再点击闪烁的福州海岸，派出默认 50% 驻军。舰队会自动渡海，在大陆建立据点。
2. 点灰色土地扩张，点接壤的敌方土地进攻。兵力会从驻军转入出征部队，逐格占领时产生真实战损；点击同一势力可追加兵力。
3. 占住大陆 20% 的土地。保留一些驻军防守，不必抽空后方。25% / 50% / 75% 仅控制本次出兵比例。
4. 撤回余部可回收仍在战场/舰上的兵力，扣 10% 撤军损耗；已发生的战损不会返还。空格暂停，暂停时仍可下令。

鼠标拖动或手机单指拖动平移；滚轮或 + / − 缩放；⌖ 恢复全图。边栏主城按钮与地图城标也能下令。关闭/隐藏网页时自动暂停。自动保存、JSON 导出与校验导入使用独立存档 key `strait-front-v1`。

## 运行与发布

```sh
npm start
npm test
npm run build
```

本地打开 `http://127.0.0.1:43993/`。无 npm install 步骤；开发脚本需要 Node.js 22+。dist 可直接发布到静态网页托管，不需要服务器、账号或 API key。

第一版是固定地图与电脑对手，没有多人联机、外交、建造或复杂舰种。是否好玩由实际试玩反馈决定，自动测试只能验证规则。

## 参考与许可

玩法方向参考 [OpenFront 官方仓库](https://github.com/openfrontio/OpenFrontIO) 的实时领土控制、持续出兵与登陆机制。本项目代码、地图、界面与程序音效独立原创，没有使用 OpenFront 的源代码、素材或商标；以 MIT 许可发布，无付费资产生成。

core.js 负责纯状态机；map-view.js 负责 Canvas 地形、边界、舰队与前线；app.js 负责交互、镜头、引导和存档。tests/ 与 docs/ 记录规则和验证范围。
