# 前线冒险 v2.0 验证记录

日期：2026-10-12。范围：浏览器游戏功能与发布；所有素材为原创程序像素绘制，无付费生成、真实电话或真人声音。

## 技术验证

43 项 Node 行为测试覆盖旧经典引擎与新战斗、冒险核心。新增测试包含独立部队命令、暂停下令、河岸与桥梁寻路、射程交战、敌军反击、掩体、驻守和撤回、真实夺旗与护送胜败、实际支援、五场景出口可达、药箱前置与防重复奖励、阶段解锁、存档范围检查与避免走进家具。

## 浏览器实际试玩

- 桥头：亲自选中步兵与机枪，移动到桥东，16 秒占住旗帜并获胜。部队生命下降证明敌军反击；军事电话实际增加可选增援部队，补给扣除 10，第二次请求禁用。
- 护送：炮兵对敌軍下达攻击，另外三支部队跟随粮车；31 秒完成。另一次练习不下护送命令，21 秒粮车被毁，明确失败并提供重试；重试入口和护送命令均可使用。
- 村庄：分别通过地面点击部署步兵、机枪、炮兵和救护队，在村口守过 50 秒，四支部队存活。全流程三场任务均完成。
- 走动：访问作战室、军营、补给站、村庄及前线指挥所。W 持续 750 ms 后，作战室人物从 y=220 实际移至 y=157.8；点击教官/仓管/医生后实际走近，才打开对话。
- 支线：仓管领取药箱 → 村庄医生交付 → 救护队加入。重复交付无第二次奖励。刷新与继续后支线及三场任务保留。
- 电话：七线路总机、营长当前任务来电、陈诚闲聊与实际增援、补给请求已操作。来电接通、话题切换、挂断和重复支援限制可用。真实战斗中呼叫救护车，受伤步兵生命从 4 恢复至 69，补给按按钮扣除。
- 存档：浏览器导出真实冒险 JSON；导入恢复三场任务和救护队。伪造 stage=99 的 JSON 被拒绝，当前战果保留。
- 模式：进入经典经营，旧独立存档可继续；返回前线冒险时三场任务仍完成。未把 v2 导入到经典引擎。
- 窄屏：设置 390×844 的视口，实际页面 CSS 可用宽度为 341；scrollWidth 同为 341，没有横向溢出。触控方向按钮从 y=220 移至 y=219.7，部队护送命令可下达。完成后恢复默认视口。
- 测试中浏览器控制台错误/警告为空。

## 限制

这是三任务的即时战术与探索游戏，没有多人联机、大规模战役或现实军事模型。当前未结算战斗刷新后重新集结，已完成任务与支线保留。手机检查使用浏览器窄屏，未在真实手机设备验证。程序音效不等于人工试听验收，玩法好不好玩仍需用户实际评价。
