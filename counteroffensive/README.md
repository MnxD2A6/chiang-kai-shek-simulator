# 渡海 · 反攻大陆 1.5

原创单人实时领土战略。新版先筹备实力，再由玩家决定开战时机；大陆由三个兵力占优的守军战区控制。经济、科技与外交可以组合发展，开战后会出现预警、空袭损伤和修复选择。本版目标是同时控制福州、南京和广州。

这是一个独立的新游戏，旧蒋介石模拟器和未完成的战斗重做草稿保留。底图使用真实地理数据，阵营与战役为架空游戏设定。

[直接试玩，无需登录](https://mnxd2a6.github.io/chiang-kai-shek-simulator/counteroffensive/)

## 战术指挥界面与海战

1.5 按海域战略与二次元战术界面方向重做：深蓝大地图、左下选中单位面板、右下四个命令，以及可收起的部队列表。原创通讯员澪升级为透明背景精细立绘。军队与舰船统一图标避让，完整名称放在列表与选中面板；移位图标有细线指向真实位置。空间不足时从列表选单位。美术资源随静态包运行，不需要生成服务或 API key。设计与立绘提示词见 [UI 设计说明](docs/tactical-ui.md)，验证范围见 [1.5 QA](docs/QA-1.5.md)。

- 初始舰队：两艘运输舰、一艘驱逐舰、一艘导弹艇。右上「部队列表」切换「陆军 / 舰队」，也可直接点地图图标，再点目的地下令。
- 运输舰自动承接附近陆军的渡海路线；缺少附近运输舰时军队等待。载兵运输舰被击沉，损失 70% 兵力并停止航行。
- 驱逐舰、导弹艇自动攻击射程内的敌舰。驱逐舰拦截附近敌方导弹。选舰后点敌舰驶近交战，点城市驶向近海。
- 「导弹打击」再点敌舰或敌方城市：发射消耗 40 资金。选中导弹艇使用其舰载弹药，否则使用岸防弹药。飞行 4 秒，命中造成实际损伤；岸防每 45 秒补一枚，最多五枚，导弹艇初始三枚。
- 舰船可花资金建造和维修。运输舰 100、驱逐舰 220、导弹艇 150；维修 60，恢复最多 80 HP。
- 开战 33 秒后朝鲜援军抵达北京（1,200 兵力和导弹艇），66 秒后俄罗斯援军抵达上海（1,800 兵力和驱逐舰）。地图可查看运输路线和剩余时间；到达后陆军向我方大陆部队推进，并参与实际反攻。
- 地图中的俄罗斯、朝鲜是架空战役的大陆支援方；可点击查看状态，地理轮廓保持 Natural Earth 数据。

新版存档使用 `strait-front-v5`，保存舰船、弹药、导弹飞行、运输关联与援军。v3/v4 进度自动迁移，原版本自动存档不覆盖。

## 怎么玩

1. 点「进入指挥」，地图上已有第一军和第二军，筹备期可以自由练习。
2. **点蓝色军队 → 点城市。** 我方城市自动移动并驻守；开战后，敌方城市自动规划路线、渡海进攻，抵达后驻守。
3. 点另一座城市即可改令；「停止 / 驻守」只停止选中的军队。「部队列表」可以选择并定位部队；左下显示名称、兵力或 HP，右下可暂停和停止命令。
4. 「补兵 +500」把预备兵补到选中部队，最多转入 500 人；必须位于我方陆地。「＋ 组建」消耗 250 预备兵，在我方城市组建新军，最多 6 支。
5. 右上「发展」打开经济、科技、外交与修复面板。经济提高收入和上限，科技减轻损失；工程需 12 秒。准备好后主动开战。
6. 同时控制福州、广州、南京获胜。驻守部队会抵抗附近敌军，留下军队守城。空袭会损伤后方部队、运输部队和设施；及时疏散和修复。

部队拥有独立身份、兵力和连续路径，不再按敌方阵营自动合并。行军与渡海保持同一支部队；路线只沿相邻地图格移动，禁止穿越外国陆地。进攻只夺取沿路狭窄通道，抵达目标后停止。

地图使用 Natural Earth 1:50m 真实海岸线和城市坐标，统一经纬度投影，包含太平洋两岸及夏威夷、阿拉斯加。「台海」回到指挥区域，「世界海图」查看合作方。点美国、日本、韩国、菲律宾可洽谈合作；「放大地区地图」查看当地城市。数据来源与许可见 [地图数据说明](docs/map-data.md)。

拖动地图平移，滚轮或 + / − 缩放。空格暂停，暂停时仍能下令；数字键 1–6 选择军队，Esc 取消选择。隐藏网页自动暂停。

1.3 版自动存档使用 `strait-front-v4`，可自动升级到本版 v5，保存每支部队的位置、兵力与尚未完成的命令。v3 地图进度自动迁移，已有军队停在原位置等待新命令；原 v3 存档不覆盖。更旧的 v1/v2 存档仍在首页 1.1 版入口恢复。

## 运行与发布

```sh
npm start
npm test
npm run build
```

本地打开 `http://127.0.0.1:43993/`。无 npm install 步骤；开发脚本需要 Node.js 22+。dist 可直接发布到静态网页托管，不需要服务器、账号或 API key。

固定地图、单人对三个电脑战区，没有多人联机。是否好玩由实际试玩反馈决定，自动测试只能验证规则。

## 参考与许可

玩法方向参考 [OpenFront 官方仓库](https://github.com/openfrontio/OpenFrontIO) 的实时领土控制、持续出兵与登陆机制。本项目代码、地图、界面与程序音效独立原创，没有使用 OpenFront 的源代码、素材或商标；以 MIT 许可发布，原创立绘由内置图像生成工具制作，没有使用外部付费素材服务。

geo-core.js 管理地理战场的领土和兵力；strategy.js 管理筹备与空袭；geo-map-view.js 渲染矢量地图，geography.js 负责统一坐标；app.js / strategy-ui.js 管理交互，marker-layout.js 处理混合单位标签避让，tactical.css 管理 1.5 的界面。tests/ 与 docs/ 记录规则和验证范围。
