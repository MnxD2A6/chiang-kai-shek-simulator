# 1.11 地图动作与指令反馈

已有赛璐璐步兵、舰船、地图和34张事件海报保留。改进范围为可辨认的机甲与驻守旗、真实受击/登岸/到达/占城反馈、目标按钮直接下令、当前指令与胜利条件说明。保持两次点击，不增加资源或战斗操作层。

地图为Canvas 2D，逻辑时间使用state.time（秒），渲染约60fps。移动由既有模拟负责；新动画只表现动作，不再次平移真实单位。暂停冻结动画，减少动态效果设置保留静态提示。

| 节拍 | 时长 | 表现与来源 |
|---|---|---|
| mech.walk | 0.72秒循环 | 四帧独立机甲；双脚交替支撑，配重落地，停下回第一帧 |
| flag.wave | 0.8秒循环 | 手绘旗帜两帧，按城市真实归属选择颜色 |
| damage.contact | 0.18秒 | 实际HP/兵力下降才显示短闪与轻微受击偏移 |
| damage.reading | 0.9秒 | 合并0.25秒内伤害，显示实际整数损失；不显示恢复为伤害 |
| landing.contact | 0.7秒 | 部队从水格回到陆地才产生登岸水花与“登岸”提示 |
| arrival.settle | 0.65秒 | 真实路线从有到无且已到目标时压缩/回弹；停止命令不伪造到达 |
| capture.raise | 1.8秒 | 城市归属变为我方时旗帜升起、扩散标记与占城文字 |
| order.ack | 0.9秒 | 成功下令后目标扩散环与方向箭头；目标由当前命令决定 |

先测试状态边沿、暂停/恢复、载入不重播、伤害数值和合法指令，再在正常速度观察动作。实际浏览器新开局完成完整胜利路线，保留每个阶段的截图、真实导出存档和复盘。验证与玩家审美接受分开。
